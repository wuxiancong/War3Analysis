# 日志
- 一律使用中文注释
- 对代码的实质修改使用成对的开始和结束标记，并简要说明修改主题，例如：
  `// --- AI 修改开始 [GAME-LIFECYCLE]：空房间销毁 ---`
  `// --- AI 修改结束 [GAME-LIFECYCLE]：空房间销毁 ---`
- 标记只包围本次新增或实质修改的最小连续代码块，不要包围整个函数或无关代码
- 修改分散在多个位置时，分别标记；属于同一主题的代码使用相同主题标识
- 标记说明使用中文；主题标识应简短、稳定，便于关联同一项修改
- 不要在标记中添加日期或模型名称；修改来源和完整历史由 Git diff 与提交记录追踪
- 删除或移除已有代码时，使用成对的删除标记，并在开始标记中用中文写明删除原因，例如：
  `// --- AI 删除开始 [GAME-LIFECYCLE]：删除重复清理调用，原因：解散流程已统一由 cancelGame 执行 ---`
  `// --- AI 删除结束 [GAME-LIFECYCLE] ---`
- 不要彻底删除已有代码；将原代码保留并注释掉，放在成对删除标记之间，开始标记写明删除原因
- 删除标记应放在原代码所在位置；若有替代逻辑，将替代逻辑放在删除标记之后
- 同一位置同时新增/修改和删除代码时，分别使用对应的修改标记与删除标记，并确保原因清晰、范围最小
