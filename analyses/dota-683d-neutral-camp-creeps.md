### 1.2 给斧王打野 AI 的 4 条硬策略结论

1. **小鸡囤野首选 `F5`（80% 全近战，且唯一远程怪伤害极低）**：
   - 中野池 5 组里有 4 组纯近战（泥土傀儡、食人魔、巨狼、半人马），唯一含远程的 `REO` 只有 2 只 `nsat`（萨特欺诈者，射程仅 **300**，攻击力仅 **7~10**），根本无法瞬秒 75 血地面小鸡。
   - **千万别让小鸡盲拉 `B5`（83.3% 含远程）或未侦查的 `I5/W5`**（`RKO` 黑暗巨魔 3 只全 500 射程，首领 49~54 攻 + 2 小巨魔 24~27 攻，齐射 100+ 直接瞬秒 75 血小鸡）。
2. **不连续刷同一组怪（`R1O` 机制）可直接用于 AI 预判**：
   - 脚本 `R1O(campId, 1, N)` 记录上一次刷出的编号 `S30[campId]`，循环重随直到 `R4O != S30[campId]`。
   - 因此如果 `F5` 当前刷的是 `REO`（中萨特），**下一次叠刷 100% 必出全近战**；如果当前是全近战，下一次叠出 `REO` 的概率是 `1/4 = 25%`。
   - 如果 `I5` 当前刷的是 `RKO`（黑暗巨魔），**下一次叠刷 100% 不会再出黑暗巨魔**。
3. **大野 `I5` 性价比极高（血量仅比中野多 3.9%，金钱高 20.9%）**：
   - 大野期望血量 **1860**（中野 **1790**），但期望金钱高达 **124.0g**（中野 **102.6g**，小野 **75.4g**）。
   - 英雄空档囤 `I5` 收益远大于囤 `B5`（每叠 1 波 `I5` 平均多赚 **+124g / +220 XP**，其中大萨特 `RDO` 高达 **150g / 284 XP**，熊怪 `RCO` 高达 **147g / 207 XP**）。
4. **静谧之鞋保护射程红线**：
   - 野区最高攻击射程是 `nfsh`（森林巨魔牧师，**600 码**，仅出现在小野 `B5/A5`），其次是黑暗巨魔 `ndtw/ndtr`、森林巨魔狂战士 `nftb`、豺狼刺客 `ngns` 及远古远程怪（均为 **500 码**），鹰身女妖巫师 `n0HX` 为 **450 码**，鬼魂 `ngh1` 为 **400 码**，萨特欺诈者 `nsat` 和鹰身女妖侦察者 `n0HW` 为 **300 码**。
   - 只要在 **>600 码外**捡静谧之鞋、在 **450 码内**提前放鞋，就不会被任何中立远程怪打碎。

### 2.2 不重复随机函数 `R1O` 与经验公式

```jass
function R1O takes integer ROO, integer G0O, integer R2O returns integer
    local integer R3O = S30[ROO]
    local integer R4O = GetRandomInt(G0O, R2O)
    loop
        exitwhen R3O != R4O
        set R4O = GetRandomInt(G0O, R2O)
    endloop
    set S30[ROO] = R4O
    return R4O
endfunction
```

- **经验公式**（War3 TFT 默认 `GrantNormalXP=25, A=1, B=5` + 6.83d `war3mapMisc.txt` 覆盖 `GrantNormalXPFormulaC=6.0`）：
  - 递推：`XP(1) = 25`，`XP(n) = XP(n-1) + 5*n + 6`
  - 对照表：**Lv1 = 25，Lv2 = 41，Lv3 = 62，Lv4 = 88，Lv5 = 119，Lv6 = 155**
- **金钱公式**（`Units_UnitBalance.slk`）：
  - `最小金钱 = bountyplus + bountydice`
  - `最大金钱 = bountyplus + bountydice * bountysides`

## 五、AI 编码直接可用的远程野怪精确白/黑名单

在 `war3hook_ai_axe_jungle.inl` 中判断一个野点是否含远程野怪时，**6.83d 全图只有以下 13 个中立远程单位 ID**（按危险度分组）：

- **高危秒小鸡（射程 400~600，攻 25~81）**：
  - 大野：`ndtw`、`ndtr`（500）
  - 小野：`nfsh`（600）、`nftb`（500）、`ngns`（500）、`n0HX`（450）、`ngh1`（400）
  - 远古：`nbwm`、`nbdk`、`n0LC`、`n0LD`（500）
- **低危短射程远程（射程 300）**：
  - 小野：`n0HW`（300，攻 28~37，3 下也能杀鸡）
  - 中/大野：`nsat`（300，攻仅 7~10，小鸡贴近即撤几乎不会死）
- **常见误判纠正**：`ngst`（岩石傀儡，远古）、`nkol`（狗头人工头，小野）、`nstl`（萨特窃魂者，中/大野）在 6.83d SLK 中均为 **100 码纯近战**，此前若按前缀误判为远程会白白错过全近战野点！
