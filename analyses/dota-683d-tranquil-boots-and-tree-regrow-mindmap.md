# 静谧之鞋与树木重生（导图）

- 静谧之鞋（6 个 ID）
  - 完好 Z00：背包 I0OG / 地上 I0OF / I0OH
  - 破损 ZI0：背包 I0OI / 地上 I0OJ / I0OK
  - 破损：带鞋攻击或被攻击（HFO 记时间）
  - 恢复：最后一次交战满 13 秒（HDO: HEO=13，HHO 换物品）
  - 地上不记交战 → 打完捡起即完好
- 树木重生
  - 每 300 秒全图一起（R50 → AB2 → AA2）
  - 250 码内有单位不长（A82）
  - -trees 立刻全长回（BY2）
- AI 规则
  - 放鞋：完好 + 350 内野怪 + 700 内无可见敌方英雄；拉野不放
  - 捡鞋：1200 内可见敌方英雄立刻捡；清完 / 380 内无野怪也捡
  - 不用隐身信息（aiCheckUnitVisibleToLocal）
  - 进区重扫树；血 < 50% 不砍
