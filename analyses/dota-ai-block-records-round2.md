## 一、核心结论摘要

第一轮 §5.1 的参数改动**确实解决了两个旧问题**（下路等兵初始前距 `gap0` 稳定提升到 `634~695`，英雄常速巡航均速 `v_hs` 从 `~155/s` 提升到 `200~228/s`），但边路常速期仍不及格（上路 `51`、下路 `37`），且上路减速期出现 `91 → 54 → 35 → 62 → 26` 剧烈波动，根因已通过 **CSV 逐帧 + `AiUnit.log` 实时诊断行 + 源码逐行审计** 100% 锁定，共有 **4 个决定性根因**：

1. **头号代码缺陷——漂移估算器 `b.medVel` + `lean` 阶跃是个高频正反馈震荡器（`L3859..3880`）**：
   - `L3860` 把 **已经过前排中点 / 单前排切换覆盖后的 `aimLat`** 当作 `med` 求导，而不是纯整波中位数。两只前排兵交替领先导致 `aimLat` 每次跳变 `20~30`（绕过 `> 32` 阈值），`dt ≈ 85ms` 算出 `±120/s` 假速度；
   - `L3869` 只要 `|medVel| > 8/s` 就叠加 `±min(35, halfW * 0.6)` 的**硬阶跃 `lean`**，在 `±8/s` 噪声边缘直接制造 `70~80` 像素方波震荡；
   - `AiUnit.log` 实锤：上路 `113623` 中 `|driftAdj| ≥ 30` 占比高达 **`40.7%`**（单帧跳变 `≥ 50` 占 `13.7%`），下路 `114223` 差波 `W27/W34` 中 `|driftAdj| ≥ 30` 占 **`34~42%`**，目标横向在 `0.3s` 内狂甩 `120~180` 像素（如 `W27` 从 `-131 → -11 → -188 → +8`），逼迫冰女以 41° 大斜角来回折返，漏兵瞬间前进速度 `v_hs` 仍被拖垮到 **`88~109/s`**。
2. **代码 Bug——边路 `splitAim` 宽排护大撮逻辑是死代码（`L3881..3884`）**：
   - 边路收紧 `aiBlockRowWidthMax()` 到 `96.0f` 后，`L3881` 在边路分支末尾无条件设置 `medianAim = true`，直接屏蔽了 `L3884`（`if (!medianAim && rowN >= 2 && hi - lo > aiBlockRowWidthMax())`）。
   - 结果当一排拉宽到 `101~185`（单英雄碰撞覆盖极限 `96` 物理上绝对挡不住）时，冰女依然傻站正中 `med`，导致两侧小兵从身旁 `±65` 同时溜走、一波连漏 `2~4` 只。
3. **上路减速期 `91 → 54 → 35 → 62 → 26` 不是随机波动，而是「代码改动 + 环境掉帧」双重叠加**：
   - `91 → 54 → 35 → 62` 完全对应当天 3 次代码改动（门口改按最前兵学习前移 `+286` → 固定等兵位偏后偏右 → 上路误开「贴身前只对准最前一排」→ 回退后立刻恢复到 `75 / 75 / 67`）；
   - `62 → 26`（`111403`）则是 **环境严重掉帧（`AiTick` 平均间隔从 `54.6ms` 恶化到 `142.0ms`，峰值卡死 `1062ms`！）** + **门口前移 `+274` 导致 `heroProj < 900` 封印推迟到 `s=1274`，跨过阈值瞬间炸出 `+59~+80` 漂移脉冲把冰女甩偏** + `kWalkOn = 280` 偏晚。
4. **物理上限与及格线错配**：
   - 冰女 `280` 对常速兵 `325`（速度比 `0.862`，天生劣势 `-45/s`），即便修复全部逻辑缺陷，常速期边路合理预期均分约为 **上路 `68~78`、下路 `55~65`**，建议按 **减速期 vs 常速期** 分开设定及格线。

## 六、问题 5：是否接近物理上限？常速期边路合理预期分与及格线建议

### 6.1 物理上限推算（冰女 `280` vs 常速兵 `325`）

1. **纯运动学劣势**：常速兵比无鞋冰女快 **`+45 /s`**（`325` vs `280`）。冰女每做一个 `25°` 斜角横移，前进分量立刻降到 `280 × cos(25°) ≈ 254 /s`（劣势扩大到 `-71 /s`）。
2. **有效挡兵预算**：
   - 冰女每次成功挡住最前兵，能迫使该兵减速/绕行约 `0.4~0.6s`（等价拖延 `130~190` 距离），但同时**其余 3 只兵在身后推挤并向两侧分流**。
   - 一旦小兵在边路弯道（近卫上路 `s = 2000~2800`、近卫下路 `s = 2500~4000`）形成横向跨度 `> 96` 的两列纵队，单英雄碰撞宽度（`2 × (32 + 16) = 96`）在物理上**必然无法同时挡住两列**——最优策略只能是「弃 1 守 3」（漏兵分 `75`）。
3. **边路长度与拖延分结构**：
   - **近卫上路**（车道长 `~5400`，不卡约 `16.6s`，拖延满分 `8.3s`）：从门口到一塔只需撑过 `1` 个大弯道（`s = 2000~2800`）。参考本轮 AI 满分波 `W19`（0 漏、拖延 `9.5s`、综合 `100`）与 `W11`（1 漏、拖延 `4.3s`、综合 `64.6`），修复 `driftAdj` 震荡与 `splitAim` 后，冰女在上路常速期能做到大部分波次 **0~1 漏、拖延 `5~8s`**，对应综合分 **`70~82`**（物理稳态均值上限约 **`75~80`**）。
   - **近卫下路**（车道长 `~8235`，不卡约 `25.3s`，拖延满分 `12.6s`）：比上路长 **`52%`**，要连续撑过 `s = 1700~2200`（出树林）、`s = 2800~4200`（南侧大弯，外侧兵常甩到 `-175`）和 `s = 6000~7500`（一塔前）3 段易漏区。即便强如真人玩家（`dota-ai-block-records-analysis.md` 提到的真人下路第 9 波拖延 `17s` 但仍漏光），无鞋冰女在 `8235` 长车道上做到全程 `0` 漏几乎不可能。参考本轮好波 `W21/W23/W25`（漏 `1~2` 只、拖延 `5.6~10.6s`、得分 `53.5~68.9`，均分 `61.8`），修复后合理稳态均分约为 **`55~65`**（物理上限约 **`68~72`**）。

### 6.2 结论与及格线分开设定建议

- **现在还没到物理上限**：当前上路 `51`、下路 `37` 离物理上限还有 **`+20 ~ +25` 分**的确定性提升空间（被 `driftAdj` 震荡、`splitAim` 死代码和掉帧吃掉了）。
