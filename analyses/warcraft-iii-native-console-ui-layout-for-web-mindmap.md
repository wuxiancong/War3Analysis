# 原生控制台 UI 布局

## 一、资源查找链

### 皮肤键
- `UI\war3skins.txt`：`[Default]` → 种族段覆盖
- 地图 `war3mapSkin.txt [CustomSkin]` 再覆盖
- FDF 里 `File "ConsoleTexture01"` 引用的就是键名

### 种族段只换这些
- 四块控制台瓦片
- 物品栏盖板 / 空格填充
- 时间指示器模型
- 鼠标指针模型
- 顶部菜单按钮精灵图
- Esc 菜单边框

### 四族共用（人族那套）
- 小地图五个按钮
- 命令按钮高亮 / 数字角标
- 经验条 / 提示框边框
- 信息面板图标

### DotA 的覆盖
- 木材图标 → 时钟
- 人口图标 → 空白
- 木材 = 分，人口 = 秒，维护费 = 版本号
- F9 按钮文字 = 地图信息

## 二、坐标系

- UI 0.8 × 0.6，原点左下
- 1 单位 = 2000 贴图像素
- 宽屏横向拉伸铺满

## 三、控制台贴图（ConsoleUI.fdf）

### 顶栏
- 高 0.032（屏高 5.33%），取贴图前 64 行
- Tile02 中段留空给时间指示器

### 底部
- 高 0.176（屏高 29.33%）
- 中间块 Tile02 只有 0.15
- ALPHAKEY：alpha 测试

## 四、顶栏帧

### 菜单按钮（UpperButtonBar.fdf）
- x = 0.002 + i × 0.085
- 宽 0.085，高 0.022
- 精灵图 v：常态 0 / 按下 0.25 / 禁用 0.5 / 高亮 0.75（ADD）

### 资源栏（ResourceBar.fdf）
- 帧宽 0.33828，贴右上
- 图标 0.0164，偏移 0 / 0.0859 / 0.1727
- 数值右对齐，字体 0.01

### 时间指示器
- 外框 256×128
- 昼夜长条横向滚动
- 网页端为静态近似

### 多面板（Multiboard.fdf）
