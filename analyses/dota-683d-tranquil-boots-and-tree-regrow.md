## 1. 静谧之鞋的 6 个物品 ID

地图物品表（`FT0` / `FR0` / `FQ0` 三种形态，同一行是一件物品）：

| 表项 | FT0（地上形态） | FR0（背包形态） | FQ0 | 含义 |
|---|---|---|---|---|
| `Z00` | **I0OF** | **I0OG** | I0OH | 完好（回血 12/s、+90 移速） |
| `ZI0` | **I0OJ** | **I0OI** | I0OK | 破损（无回血，-25 移速） |

- 丢在地上会变成 FT0 形态：完好鞋在地上是 **I0OF**（2026-11-27 实测地上扫到 I0OF），破损鞋在地上是 **I0OJ**。
- 旧 AI 只认 I0OG / I0OI，所以丢下后在地上找不到鞋，18s 后放弃，把鞋留在野区。已修：6 个 ID 全认。

## 2. 破损与恢复：最后一次交战后 13 秒

```
function HFO takes unit u          // 攻击 / 被攻击时调用（只在英雄身上带鞋时）
    SaveReal(LY, handle(u), 730, TimerGetElapsed(M))      // 记最后交战时间
function HDO takes unit u returns boolean
    local real HEO = 13
    return LoadReal(LY, handle(u), 730) >= now - 13       // 13 秒内交过战 = true
function HHO takes unit u          // 周期性对所有带鞋英雄调用
    完好(Z00) 且 HDO → 换成破损 FR0[ZI0]=I0OI
    破损(ZI0) 且 !HDO → 换成完好 FR0[Z00]=I0OG
```

- 触发记时间：`LYO` / `LJO` 在攻击事件里对攻击者和被攻击者都调用；`LYO` 先检查单位**身上有鞋**（`EA1(u, FR0[Z00])` 或 `FR0[ZI0]`），没带鞋就不记。
- 结论：
  1. 鞋破了要**最后一次攻击 / 被攻击后满 13 秒**才恢复。
  2. 打架时鞋放在地上，不会记交战时间 → 打完捡起来，只要上次带鞋交战已超过 13 秒，**捡起来就是完好的，立刻回血**。这就是「打前丢、打完捡」的收益。
  3. 拉野（打一下就跑）如果带着鞋，会记一次交战，13 秒内鞋是破的。

## 3. 树木重生：每 300 秒一次，全部同时长回

```
call TriggerRegisterTimerEvent(R50, 300, true)            // 每 300 秒（重复）
R50 → AB2: EnumDestructablesInRectAll(全图, AA2)
AA2: 死树（生命 < 1，排除两种特殊可破坏物）且 A82(树)==false → DestructableRestoreLife(满血)
A82: GroupEnumUnitsInRange(树坐标, 250, D51) 有单位 → true（不长）
```

- 结论：
  1. 全图死树**每 5 分钟一起长回**，不是每棵树单独计时。
  2. **树 250 码内有单位时不会长回**（`A82`），等下一个 5 分钟。
  3. 玩家 `-trees` 指令（`BY2`）也会立刻让全图死树长回。
