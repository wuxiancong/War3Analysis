## 一、必须优先修复的 UI / HUD 问题（Gemini 受红线限制不能改其他源文件）

用户实机观察后明确指出的 3 个 HUD 问题（涉及 `war3hook_memhud.cpp` / `war3hook_overlay.cpp` 等非 `war3hook_ai_axe_jungle.inl` 文件）：

1. **ComboBox 中「任务」文字显示错位 / 顶部被裁切**
   - 现象：用户截图显示托管信息面板下拉框选中「任务」时，文字明显偏上、顶部笔画贴边/裁切，与右侧下拉三角 `▼` 未垂直居中对齐。

2. **面板中的文字过于紧凑、难以阅读**

   - 需改进：加大行高/内边距、优化字体/颜色区分，或精简每行前缀宽度。
3. **托管信息面板与所有自定义按钮位置未持久化记住**
   - 现象：用户反馈「托管信息面板的位置没有记住，以及所有面板和自定义按钮（如：设置、内存 Mini 按钮、AI Mini 按钮）的位置没有记住」，重开局后回到默认位置。

### 2.2 实机踩出的核心困难与已做/未做项

1. **经济缺口硬约束（需评估 + 优化双野效率）**：
   - DotA 6.83d **跳刀实价为 `2250` 金**（`DotaItemShopAbbrev.h:97`，非任务书写的 2150）。
   - 总开销：出门 595 + 大药 1~2 瓶(110~220) + 静谧之鞋 1000 + 跳刀 2250 = **3955~4065 金**。
   - 减去起始 625 + 10 分钟自然工资 1000 = 1625，**10 分钟内必须纯刷野/吃符挣到 2330~2440 金**（约 21~23 波野，或 19~20 波野 + 2~3 个金币符）。
   - v9/v10 已实装：0:00 金币符(+100g/xp)、远程买装+小鸡运货、坐标直砍树（T6 + P25 两棵树）、双野同拉同打（v9 2:23 升 4 级），但 **v10 刚跑 1:21 即被用户叫停，尚未跑完完整 10 分钟验证**。
2. **静谧之鞋 1.26 丢/捡与防抢机制（高风险点）**：
   - 实测发现：DotA 6.83d 中若丢下失效形态 `I0OI`，地上变身回 `I0OG` 会换对象 ID，导致右键旧 ID 死循环卡死（v5_r1 卡死 3.5 分钟）。
   - 同时在 **War3 1.26.0.6401** 下，`GameEnumWidgetsInRect(0x04F70000)` 枚举地上 `I0OG` 未命中（v6/v7 因此误判鞋消失而提前放弃，导致 6:00~10:00 裸脚打野）。
   - v9/v10 已改为：只丢完好 `I0OG`（脚边 30 码，1400 码有敌英雄不丢）、1200 码见敌英雄最高优先捡回、每清完一波野或 380 码无怪立刻捡回、不做 4s 误放弃。**建议 Claude 在 1.26 下核实地上物品枚举回调偏移，实现真正的地上鞋实时追踪。**
3. **开树范围还不够彻底（用户提示）**：
   - 用户建议：「实在不行，你就把所有树都吃开，避免多走路径。」

4. **双野同拉同打与 :50 囤双野的衔接**：
   - v9/v10 的 `dualStep` 只把 E5+B5 拉到一起打，但 :47.5 双野囤野（同时拉 E5+B5 出盒 = 四波野）在没鞋/移速不够时容易超时漏拉第二个点；可结合砍开更多树缩短直线距离，并实测验证幻象符拉双野（6 轮测试里尚未刷到幻象符，未动态验证 `aiAxeTickIllusions` ❓）。
