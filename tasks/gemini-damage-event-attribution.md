`War3Launcher/versions` 下**全部 11 个版本**都要给出 RVA（`.agents/rules/war3-gamedll-all-versions.md`），每条结论要有反汇编证据。

2. **`EVENT_UNIT_DAMAGED` 的派发点**：`GetEventDamage` / `GetEventDamageSource` 读的数据是在哪里写入的？如果在这里挂钩更方便，给出挂钩点和能读到的字段。
3. **挂钩方案**：给出一个只读的挂钩方案——在哪条指令处、用什么方式拿到「来源 obj、目标 obj、最终伤害」，在游戏主线程，不改伤害、不改流程。参考现有 hook 框架 `War3Launcher/hooker/war3hook_engine.cpp`、`war3hook_offsets.cpp` 的写法（只读参考，不要改）。
4. **区分来源类型**：拿到来源单位后，怎么判断它是英雄 / 小兵 / 塔 / 其他（类型 ID、`IsUnitType` 的标志位），列出 6.83d 两边一塔到高地塔、兵线小兵、攻城车的类型码。
