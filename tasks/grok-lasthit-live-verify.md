## 要做的事

1. **实机核验**（1.27，只读内存），每项给样本数和误差：
   - 小兵 / 英雄的当前攻击目标 `+0x6C/+0x70` 是否等于目标的 `CUnit+0x0C/+0x10`；
   - 前摇 / 冷却 / 后摇计时器 `+0x1EC` / `+0x1D8` / `+0x200` 的剩余时间；
   - `g_AgentManager` 里飞行中弹道的枚举，以及来源、目标、伤害、弹速、位置；
   - 近战兵、远程兵、攻城车每一下的预测伤害和实际掉血。
2. **指令延迟分解**：从发出攻击指令到前摇开始，这局中位约 0.5s。分清转身、剩余冷却、网络 / 动作队列延迟各占多少，给出 AI 可以实时算出来的公式。
3. **证明更准**：采一段中路对兵（至少 30 只兵死亡）的 20Hz 以上样本，离线对比「逐次预判」和「掉血速度」在 1.0 / 1.25 / 1.5 秒后的血量误差，以及一刀补中率。目标：一刀补中率 ≥ 85%；达不到就写明还差什么。
4. **版本**：凡是用到的 `game.dll` 地址和偏移，按 `.agents/rules/war3-gamedll-all-versions.md` 覆盖 `War3Launcher/versions` 下全部版本，没确认的明确标出。
5. **给实现者**：伪代码（输入、每 tick 步骤、出手判据、开销），能直接替换 `war3hook_ai.cpp` `aiTickRoutine` 里的 `predicted`。
