## 要做的事

`War3Launcher/versions` 下**全部 11 个版本**都要给出 RVA（`.agents/rules/war3-gamedll-all-versions.md`），每条结论要有反汇编 / 地图数据证据。

1. **合成**：6.83d 支配头盔的配方（组件物品 ID、价格、是否需要卷轴）、在哪个商店买（近卫 / 天灾各自的商店单位 ID 和坐标、秘密商店 / 野外商店能不能买）、合成是不是背包里凑齐就自动合（地图脚本还是引擎物品合成，`war3map.j` 行号）。给出 AI 用现有 `-buy` 流程买齐并确认合成成功的步骤（怎么从背包读到 `I08T`）。
2. **支配**：`A2V4` 的确切指令 ID（`ANcl` 按 `DataB1` 推导后的值）、用物品的动作包格式（`0x12` 对单位目标 + 物品栏位 / 物品对象 ID，参考 hook 现有的 `-use` 实现）、可以支配的 6.83d 野怪类型（哪些营的哪些单位能 / 不能：远古、魔免单位），支配后单位是**永久**还是有时限、最大同时几只、支配后的单位归属 / 血量 / 技能变化（例如半人马的践踏、萨特的净化、狼人的召唤等技能能不能用、AI 怎么用）。
3. **控制被支配的单位**（重点）：
   - 用玩家动作包选中**非英雄的自己单位**（选择 / 子组切换动作 `0x16` / `0x19` 等的格式），对它下 move / attack / hold，再切回英雄——给出完整动作包序列，以及切换选择对英雄当前指令有没有影响（会不会打断英雄在做的事）。
   - 有没有办法**不切换选择**就给某个单位下指令（编队 / 控制组 `0x17` / `0x18`、或者其他动作类型）？
   - hook 里怎么找到这只单位：支配后它的拥有者变成本地玩家 → 用现有的单位跟踪表（`g_aiUnits`，`GetOwningPlayer` + `GetUnitTypeId`）就能认出来吗？给出判断条件。
4. **用被支配的野怪囤野**：
   - 野怪攻击另一营野怪时，会不会被当成「敌人」被追（中立敌对之间的仇恨规则：被支配的单位属于玩家，应该会被追）？拴绳 / 回巢规则和英雄拉野一样吗？
   - 近卫 6 个野点里，用哪种被支配的野怪去囤哪个点最合适（射程、移速、血量、会不会被野怪秒掉）；它被打残了怎么办（自然回血 / 回泉水）。
   - 一只被支配的野怪能不能**轮流囤多个野点**（例如 :50~:53 囤 W5，下一分钟囤 F5），还是固定一个点更稳。
   - 它站在别的野点的封野盒里会不会**封住那个野点**（`dota-neutral-camp-spawn-box.md` 说召唤物在盒里会封野——确认被支配单位算不算）。
5. **给 hook 的实现方案**（写成文档里的伪代码 / 状态机，不改源码）：
   - 自动购买合成（钱够了就买）→ 支配（选哪只、在哪）→ 被支配单位的囤野循环（复用现有的站位 / 弧度 / :50~:53 出手 / 带野 / 防挨打逻辑，只是被控制的单位换成这只野怪）→ 和英雄自己的动作怎么错开（选择切换的时机，别打断英雄补刀 / 带野）。
   - 需要 Claude 在 hook 里新增的东西：读物品栏判断 `I08T`、单位跟踪里认出被支配单位、选中非英雄单位下指令的动作包。
